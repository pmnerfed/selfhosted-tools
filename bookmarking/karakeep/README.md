# Bookmarking workflow

1. Setup Karakeep
2. setup Singlefile as mentioned at https://docs.karakeep.app/integrations/singlefile/

Now you have the ability to annotate your pages and directly save the html along with notes and annotations to Karakeep

Advantages:
- Does a much better job at adding correct title and content.
  - What you see in your browser is saved directly.
  - bypasses headless chrome usage for fetching content.
- add annotations and notes directly wihtout any extra tools.
